# 常规设置

「常规设置」管理语言、外观和窗口关闭行为。

## 语言

默认跟随 Windows 的显示语言。内置简体中文和 English，也可以导入自己的翻译。

下拉列表里每一项后面标着来源和翻译覆盖率，例如「Deutsch · 本地文件（1%）」。覆盖率不满 100% 时，缺失的条目回退成英文。

| 来源 | 说明 |
| --- | --- |
| 跟随系统语言 | 使用 Windows 的显示语言 |
| 内置 | 随程序发布 |
| 本地文件 | 从 `.ftl` 导入 |

**切换语言需要重启 OpenDS**。选中后页面会提示「语言设置将在重启 OpenDS 后生效」，重启时弹窗确认，可以选「现在重启」或「稍后」。

重启会短暂断开虚拟手柄，正在进行的录音和文件记录也会停止。

### 导入语言文件

1. 点「导入语言文件…」，选择 Fluent 格式的 `.ftl` 文件。
2. 如果这门语言已经有翻译，会询问是否用本地文件替换。
3. 选中新语言，重启 OpenDS。

「打开语言文件夹」可以直接往目录里放文件。文件必须是 UTF-8 编码。

导入前可以先校验内容：

```powershell
opends.exe language check my-lang.ftl
```

输出会列出缺失的条目、已翻译条数和覆盖率。

## 外观

| 选项 | 说明 |
| --- | --- |
| 随系统 | 跟随 Windows 的浅色/深色设置 |
| 浅色 | 固定浅色 |
| 深色 | 固定深色 |

切换立即生效，不需要重启。标题栏、控件和弹出窗口会一起改变。

## 关闭时行为

| 选项 | 说明 |
| --- | --- |
| 询问 | 每次关闭都弹窗确认 |
| 最小化到托盘 | 关掉窗口后在托盘继续运行 |
| 退出 | 关闭即停止桥接并退出程序 |

选了「最小化到托盘」或「退出」之后不再询问。想恢复每次确认，回到这里改回「询问」。
