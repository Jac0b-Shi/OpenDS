# 实时监视

在游戏运行时观察手柄输入和音频链路。入口：**概览 → 实时监视**。

## 采集控制

默认不采集，点「开始采集」后开始记录。不点不会影响桥接。

| 按钮 | 作用 |
| --- | --- |
| 开始采集 | 开始记录并刷新画面 |
| 停止采集 | 冻结当前历史，已采集的数据保留 |
| 清空 | 丢弃历史。采集仍在进行时从空历史继续 |
| 独立窗口 | 弹出为独立窗口，可调整大小，默认置顶 |
| 收回窗口 | 关闭独立窗口，可视化回到主页面 |

开关、采样率、刷新率和时间跨度由主页面与独立窗口共享，同一时刻只有一份画布在绘制。

## 手柄显示

左侧是二维 DualSense，显示方向键八个方向、四个面键、L1/R1、L2/R2、L3/R3、Create、Options、PS、触摸板按下和静音键。

摇杆显示实时二维位移与数值，扳机显示连续行程。触摸板显示两个触点的位置与激活状态。连接 Edge 时额外显示 Fn 和背键。

按键有下压、高亮和释放过渡。刷新间隔内发生的短按会保留一次视觉反馈。断线后按键立即释放、摇杆居中并标注未连接。

## 波形

右侧纵向排列三组波形。

| 组 | 源信号 | 转发信号 |
| --- | --- | --- |
| 扬声器 | 游戏四声道 PCM 的前两声道 | 下混、重采样后，编码前的 PCM |
| 触觉 | 同一四声道 PCM 的后两声道 | 增益、降采样及传统震动混合后的最终数据 |
| 麦克风 | 手柄 Opus 解码后的单声道 | 送入虚拟 USB 麦克风接口的双声道帧 |

默认只采集源信号，用蓝色实线绘制。勾选「转发信号」后叠加橙色虚线，并显示对应图例。

扬声器和触觉分左右两条轨道，麦克风为单声道。纵轴固定为满量程的 −100%～+100%，不自动放大；S16 和触觉 S8 按各自满量程归一化。

关闭某类信号会停止采集并移除对应历史，重新开启只记录此后的数据。

## 采样与刷新

| 项 | 可选值 | 默认 |
| --- | --- | --- |
| 采样率 | 20 / 50 / 100 / 200 Hz | 100 Hz |
| 刷新率 | 15 / 30 / 60 FPS | 60 FPS |
| 时间跨度 | 30 / 60 / 120 / 300 / 600 / 900 秒 | 60 秒 |

采样与刷新互相独立，都不改变手柄本身的音频采样率。

每个时间桶保存最小值和最大值，绘制时保留峰值包络。拉长时间跨度后短促峰值仍然可见。滚动位置按单调时钟计算、连续平移，不按整数桶跳格。

## 状态提示

| 显示 | 含义 |
| --- | --- |
| 尚未采集 · 手动开启，不影响桥接 | 还没点「开始采集」 |
| 等待手柄 | 没有检测到已配对的手柄 |
| 未连接 · 等待输入 | 设备存在但流未建立 |
| 等待新的输入报告 | 已连接，暂无新数据 |
| 数据中断 > 500 ms | 超过 500 毫秒没有收到数据 |
| 已停止 / 历史冻结 | 点了「停止采集」 |

短暂无数据时背景轨道保持连续，超过 500 毫秒才标记为中断。**已确认丢失的数据显示为缺失区域**，不连接前后振幅，也不补成静音。这样波形既保持可读，也不会掩盖真实的丢包。

## 统计行

底部一行显示丢弃、解码失败、流重置和缓存占用。这三个计数用来判断数据缺失的原因：队列溢出、解码出错，还是流本身被重置。

## 资源占用

遥测队列、历史和汇总缓存合计上限 32 MiB，不保存长时间原始 PCM。

隐藏或最小化全部监视画布后继续采集，但停止绘制和动画唤醒；恢复可见时显示最新状态。关闭监视不保留后台线程。

采样率、刷新率和时间跨度会被记住，采集状态每次启动都从停止开始。
