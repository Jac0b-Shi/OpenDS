# 登录自启与长期常驻

建议先将完整发布包安装到固定目录，再开启登录自启：

```powershell
.\scripts\Install-OpenDS.ps1 -Startup
```

默认安装位置为 `%LOCALAPPDATA%\Programs\OpenDS`，保留现有配置。日常运行不要求管理员权限。Windows 登录后启动托盘模式，自动等待蓝牙手柄；登录前不会运行。Windows 可能延迟启动项，启动游戏前先确认桥接已连接。

设置界面的“登录 Windows 时在托盘运行”可单独开关，与“打开 OpenDS 时自动开始桥接”相互独立。也可从安装目录执行：

```powershell
.\opends.exe startup enable
.\opends.exe startup status
.\opends.exe startup disable
.\opends.exe tray
```

`tray` 不显示主窗口，重复后台启动会复用已有进程。点击托盘图标可以打开设置，从托盘退出会停止桥接并恢复本次新增的隐藏状态。当前使用用户登录启动项，不安装系统服务，也不提供操作系统级的崩溃自动重启。

## 后台开销与日志

虚拟输入等待新的蓝牙输入快照，减少重复处理；不修改 USB 身份或原生触觉格式。界面隐藏后降低状态检查频率，跳过控件与日志文本刷新。

诊断日志位于 `%LOCALAPPDATA%\OpenDS\logs`。最多保留当前文件和两份轮转，每份上限 1MiB；内存活动列表最多 200 行。第三方工具重定向的标准错误文件由该工具管理，不受此轮转限制。

不同游戏、音频、麦克风和连接状态的占用不同。麦克风仍为实验功能，默认关闭；更新不会擅自覆盖用户已有的麦克风设置。

## 验证一周运行

在固定安装目录打开 PowerShell，运行只读采样：

```powershell
.\scripts\Measure-Resident.ps1 -Hours 168 -IntervalSeconds 60
```

工具不改变桥接状态。报告默认保存于 `%LOCALAPPDATA%\OpenDS\measurements`，每分钟记录 CPU、私有内存、工作集、句柄和线程，并保留实际观察时长。它不自动重启退出的进程。可比较相同连接及游戏状态下的趋势，不能只用一次工作集上升判断泄漏。

本版本已通过软件测试、GUI 启动、托盘自动连接、重复启动、音频端点及声道设置保留，并经用户确认原神震动和菜单扬声器声音正常。尚未完成连续七天实跑或系统重启、注销、睡眠恢复等长期场景验收，不能据此承诺数周无故障。

## 更新与回退

更新前从托盘退出旧 OpenDS，再执行安装脚本。配置在 `%LOCALAPPDATA%\OpenDS\opends.ini`，不随版本覆盖。固定安装位置可避免自启项指向已经删除的临时目录；不要在每次运行时更改虚拟设备身份。Windows 的音频显示编号不会因为升级自动清零。
