# OpenDS 使用指南

## OpenDS 是什么

OpenDS 让蓝牙连接的 DualSense（PS5 手柄）在本机表现为一只 **USB 有线 DualSense**，并把游戏写入虚拟设备的所有反馈——灯条、自适应扳机、震动、音频——原样送回真实手柄。

解决的痛点：PC 上大量游戏对蓝牙手柄只提供"精简支持"，而 USB 有线才被当作全功能设备。

```
蓝牙手柄  ←→  OpenDS  ←→  虚拟 USB DualSense  ←→  游戏
             │
             └─ 双向：输入转发 + 反馈（灯光/扳机/震动/音频）回传
```

## 环境要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10/11 x64 |
| 手柄 | DualSense（VID `054C` / PID `0CE6`），通过**蓝牙**连接 |
| 驱动 | HidHide（隐藏物理手柄）+ usbip-win2 UDE（虚拟 USB 设备） |
| 可选 | libopus（音频功能，发布包已内置） |

“诊断与日志”页面的安装按钮会下载、校验并打开官方驱动安装向导。缺少或无法访问运行依赖时，侧栏该菜单显示红点；重新检查或安装完成后会更新。安装前需停止桥接。下载优先尝试指定的代理或环境代理，然后使用 Windows 系统网络设置（支持 PAC 自动配置与直连），失败后再尝试直连；不要求用户配置代理。只有所有下载方式都失败时，日志才提供手动下载地址。向导需要管理员确认，是否重启按安装器提示执行。

脚本默认只下载与校验，传入 `-Install` 才会安装。

### 手动指定依赖目录（0.3.2 起）

已安装依赖却提示工具未找到时，打开「诊断与日志」，在相应组件下点击「选择目录…」。USB/IP Win2 目录应包含 `usbip.exe`；只找到图形界面 `wusbip.exe` 不足以供 OpenDS 挂接设备。HidHide 可选择包含 `HidHideClient.exe` 的目录，也支持该文件位于 `x64` 或 `bin` 子目录的安装布局。

目录通过校验后立即保存并重新检查，不需要再次点击保存设置；选错或取消不会覆盖原设置。「自动查找」会清除该组件的手动目录，恢复默认目录和 PATH 查找。使用手动目录时，工具被移动或删除会明确提示，不会静默改用其他安装。桥接或安装进行中不能修改目录。

HidHide 的驱动与配置工具分别检测：OpenDS 直接访问驱动，配置工具缺失不会阻止桥接。指定目录后可点击「打开 HidHide 配置」；指定目录不能解决驱动未安装、未启动或权限不足的问题。

## 快速开始

```powershell
# 1. 安装驱动（首次运行，需要管理员）
powershell -ExecutionPolicy Bypass -File scripts/Install-Drivers.ps1 -Component all -Install

# 2. 启动桥接
opends.exe bridge
```

启动后：

1. 物理手柄被隐藏（其他程序只看到虚拟设备）
2. 虚拟 USB DualSense 出现
3. 游戏正常识别为有线手柄

**先启动 OpenDS，再启动游戏**——游戏一般在启动时探测手柄类型和支持的能力。中途接入的手柄仍能当输入设备用，但能力探测不会重跑，震动、自适应扳机和灯效可能不生效。

## 命令

| 命令 | 说明 |
| --- | --- |
| `opends.exe bridge [秒数]` | 桥接指定时长，默认 30 秒 |
| `opends.exe restore` | 恢复 HidHide 配置（异常退出后使用） |

`opends.exe restore` 是安全网：如果程序因断电、崩溃等原因异常退出，物理手柄可能仍处于隐藏状态，执行该命令即可恢复。

## 配置

程序从工作目录读取 `opends.ini`：

```ini
[ds5]
; 虚拟设备端口（默认 3240）
port=3240
; 音频抖动缓冲块数，16-128（默认 64）
buffer=64
; 音频功能开关
audio=1
; 触觉强度 10-20（默认 10）
haptics_gain=10
```

改动后需重启桥接生效。

## 监视与麦克风

**实时监视**（概览 → 实时监视）显示手柄按键、摇杆、触摸板和扬声器、触觉、麦克风三组波形。默认不采集，点「开始采集」才开始记录，不影响桥接。详见[实时监视](monitor.md)。

**麦克风**默认关闭。开启后可调整增益（0–50 dB，带峰值限幅）和抖动缓冲（16–512 毫秒）。「连接与反馈」里的「麦克风测试…」能录 5 秒并分别回听蓝牙端与 USB 端，用来定位问题出在解码还是转发。详见[麦克风](microphone.md)。

## 语言与外观

「常规设置」里可以切换界面语言（跟随系统、内置或导入 `.ftl` 文件）、选择外观（随系统 / 浅色 / 深色），以及设置关闭窗口时的行为。

语言切换需要重启 OpenDS，重启会短暂断开虚拟手柄；外观切换立即生效。详见[常规设置](settings.md)。

## 指令表

「实时监视」开始采集后，手柄图形下方出现指令表，记录按键、摇杆方向与力度变化。右摇杆默认不记录，可在「指令表设置」打开；来源标识支持文字、图标或隐藏。

当前状态在最上方并持续计时，历史行显示该状态持续到下一次变化的时长，超过 99 秒显示 `99+ s`。断开和重连显示为插头事件。

点「悬浮窗」可独立显示指令表，支持置顶、拖动缩放、背景与内容分别调透明度、跟随软件或固定深浅主题。锁定后鼠标穿透，在主面板或托盘菜单解锁。

开启「记录文件」会另存一份同名 `.commands.csv`，不会覆盖已有文件。时间以软件收到输入的时刻为准，不按游戏帧数换算。

## 常见问题

**手柄在设备管理器里消失**
物理手柄被 HidHide 隐藏了，这是预期行为。退出 OpenDS 会自动恢复；若未恢复，执行 `opends.exe restore`。

**游戏里没有震动**
1. 确认**先启动 OpenDS，再启动游戏**
2. 检查游戏中是否把音频输出设为手柄扬声器（部分游戏的触觉信号走音频通道）
3. 确认手柄扬声器音量不为零（由游戏通过输出报告设置，游戏没有相关选项时保持上一次的值）

**有震动但没有声音**
手柄扬声器的音量独立于系统音量，由游戏通过输出报告设置；游戏没有相关选项时保持上一次的值。确认 `opends.ini` 中 `audio=1`。

**自动弹出放大镜或屏幕键盘**
Steam 的导航键组合键会把 PS 键加组合键翻译成系统快捷键。关掉它：Steam → 设置 → 控制器 → 高级设置 → 取消勾选「启用控制器的导航键组合键」。

**音频断续或有爆音**
增大 `buffer`。默认 64 块约合 683 ms 缓冲，每块约 10.7 ms，调到 96 块约 1.02 秒、128 块约 1.37 秒。**代价是游戏声音进一步落后画面**，只在确实出现卡顿时调大。
